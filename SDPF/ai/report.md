# 多模态神经网络工作汇报：振动序列与GAF图像融合

## 1. 核心工作总结
本周主要工作集中在 **多模态神经网络 (Multi-Modal Neural Network)** 的构建与优化上。针对单一振动序列特征提取的局限性，引入了 **格拉姆角场 (Gramian Angular Field, GAF)** 技术，实现了“一维时间序列”与“二维图像特征”的联合建模。此外，设计并完成了消融实验，以验证多模态融合的有效性。

## 2. 技术路线与方法

### 2.1 多模态融合架构
构建了一个多模态自编码器，旨在同时捕捉信号的时间依赖性和空间结构特征。
- **模态 A (Sequence)**: 原始一维振动信号，经过归一化处理。
- **模态 B (Image)**: 通过 GAF 变换将时间序列转化为二维图像，将时间相关性映射为空间纹理。

**模型结构设计 (`Model Architecture`)**:
1.  **双路编码器 (Dual Encoders)**:
    - `Cnn1dEncoder`: 深度一维卷积网络，提取序列时序特征。
    - `Cnn2dEncoder`: 二维卷积网络，提取 GAF 图像的空间特征。
2.  **特征融合 (Fusion)**: 将两路 Latent Vector 进行高维映射与融合。
3.  **联合解码与重构**: 模型同时输出重构的序列和重构的图像，损失函数综合考量两者误差。

### 2.2 训练策略优化
在模型训练过程中，解决了欠拟合、过拟合及加载报错等问题，采取了以下关键措施：
- **防止过拟合**:
    - **Early Stopping (早停机制)**: 监测验证集 Loss，连续 15 个 Epoch 不下降则提前终止训练。
    - **Dropout 正则化**: 在 Encoder/Decoder 关键层引入 Dropout (p=0.3)，增强模型泛化能力。
    - **保存最佳模型**: 始终保留验证集表现最优的模型参数 (Best Checkpoint)。
- **训练稳定性**:
    - **梯度裁剪 (Gradient Clipping)**: 防止训练初期的梯度爆炸。
    - **学习率调度 (Scheduler)**: 使用 `ReduceLROnPlateau`，在 Loss 平台期自动衰减学习率。
    - **Batch Normalization**: 加速收敛并防止梯度消失。
- **工程修复**: 修复了 PyTorch 新版本 `weights_only=True` 导致自定义模型类加载失败的问题，实现了稳健的模型存取接口。

## 3. 消融实验 (Ablation Study)设计
为了科学验证引入 GAF 图像模态的必要性，设计了控制变量的消融实验。

**实验设置**:
- **实验组 (Multi-Modal)**: 完整的序列+GAF多模态模型。
- **对照组 (Seq-Only)**: 剔除图像分支，仅保留序列处理分支的模型（保持相同的层数和参数量级）。
- **评估方法**:
    1. 使用完全相同的数据集划分进行训练。
    2. 在未见过的测试集 (Test Shots) 上进行推理。
    3. 对比指标：序列重构的 **MSE Loss**。

**代码实现**:
已编写自动化脚本 `ablation_study.py`，包含：
- `SeqOnlyAutoencoder` 类定义。
- 自动化训练流程。
- `compare_models` 函数：加载两个训练好的模型，在同一批次数据上计算 Loss 并绘制对比曲线。

## 4. 结果展示与分析
*(此处可根据 ablation_study_result.png 的实际图表填充具体结论，例如：)*

- **训练收敛性**: 经过优化后的训练策略，Train Loss 与 Val Loss 差距显著缩小，模型收敛稳定。
- **模态有效性**: (预期结论) 多模态模型在复杂或带有噪声的工况下，重构误差应低于单模态模型，证明 GAF 提供了额外的鲁棒特征信息。

## 5. 后续计划
- **详细评估**: 对消融实验结果进行量化分析，计算 MSE 降低的百分比。
- **异常检测验证**: 将模型应用于实际故障 Shot，对比多模态与单模态在故障检出率上的差异。
- **融合策略探索**: 尝试不同的特征融合方式（如 Attention 机制）以进一步提升效果。
